# Contributing

Tạo branch theo dạng `feature/ten-ngan` hoặc `fix/ten-loi`. Trước pull request, chạy lint, typecheck và build.

Pull request cần mô tả vấn đề, giải pháp, ảnh desktop/mobile nếu đổi UI và cách đã kiểm thử. Nội dung giáo dục phải ghi rõ cấp học, mục tiêu và được giáo viên duyệt tính chính xác.

Không commit dữ liệu học sinh, API key, `.env`, `node_modules` hoặc output build.
